## Important before public launch
- The header currently uses a temporary AV text mark. Replace it with the owner's exact official AUREVIA INTERIORS logo file, unchanged. The original logo has not been embedded in this ZIP.
- Confirm contact details and replace generic social links with the official page URLs.
- Portfolio images are illustrative stock references, not completed AUREVIA project claims. Replace them with approved project photographs.
- The language toggle is currently implemented on the home page only. Translate and test all remaining page content before advertising the site as fully bilingual.
- Client/admin pages are visual previews only. They are NOT secure login systems and have no database. Do not collect customer data until backend authentication, role-based access, validation and secure storage are implemented.
- External Unsplash and Google Fonts assets need internet access. Self-host licensed assets for a fully self-contained site.
